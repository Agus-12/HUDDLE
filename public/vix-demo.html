¿Cómo se autocura?
1. Detecta: cada 10 min pide https://vix.com/detail/video-4285473 y busca anvack en el HTML/JSON.
2. Falla: si el MPD da 403 o la key L3 es inválida → marca VIX_TOKEN_ROTADO.
3. Cura: refresca anvack/anvtrid desde api.vix.com (1 request), reintenta MPD + key, cachea.
4. Riesgo: rota cada 2-3 meses. 90% se cura solo en <30s. Si cambian toda la API (1 vez/año) → 1 día parche + fallback vivo mientras.
